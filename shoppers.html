For agents

Declared, verified, authorized.

Any agent can read the MerchantLink catalog if it identifies itself and acts for a shopper who authorized it. Every merchant behind it is verified.

Catalog access

Verified merchants, hardened catalogs, live stock and offers, in CAD, province by province. Planned endpoints: MCP, UCP and ACP.

Network agent tokens

Mastercard requires agent registration and verification before any Agent Pay transaction.3 Visa onboards agents to Intelligent Commerce, and the cardholder sets up a passkey at enrolment.4

Wallets

Agents can also pay through wallets, for example single-use cards for each approved purchase.5 Orders complete. Points and the bank's basket view apply only when the bank's own card or token pays.
